# GASMAS Calibration Assessment — 763 nm vs 935 nm

Pathlength distribution analysis for **GASMAS (Gas in Scattering Media Absorption Spectroscopy)** in external illumination mode. This notebook compares lung air pathlength distributions at two wavelengths — **763 nm** (O₂ A-band) and **935 nm** (H₂O absorption) — using detected-photon data from pre-run Monte Carlo simulations.

The analysis assesses whether the two wavelengths probe the same lung volume, which is a prerequisite for using the 935 nm channel as a pathlength calibration reference for the 763 nm GASMAS signal.

---

## Prerequisites

This notebook does **not** run any simulations. It requires `.npz` output files already generated by the Monte Carlo simulation notebooks for both wavelengths:

```
gasmas_simulation_results_20mm.npz       # 763 nm (O₂)
gasmas_H2O_simulation_results_20mm.npz   # 935 nm (H₂O)
```

See `Monte_Carlo-External.ipynb` for how to produce these files.

## Usage

Open `GASMAS_calibration_assesment.ipynb`. Set the data path and SDS list near the top:

```python
DATA_ROOT   = '/content/drive/MyDrive/your_folder_here'
SDS_LIST_MM = [5, 10, 15, 20, 25, 30, 35]
```

Run all cells in order. The notebook follows an 8-step analysis pipeline:

| Step | Analysis |
|---|---|
| 1 | Histograms of lung pathlength distributions — both wavelengths, all SDS |
| 2 | Combined boxplots — both wavelengths per SDS |
| 3 | Mean pathlength vs SDS |
| 4 | Median ± IQR vs SDS |
| 5 | Comprehensive statistics table (mean, median, std, IQR, skewness) |
| 6 | Distribution similarity metrics — KS test, Wasserstein distance, JS divergence, overlap coefficient |
| 7 | GMM decomposition — separate each distribution into short and long pathlength components |
| 8 | Repeat steps 1–6 on the short and long GMM components separately |

---

## Outputs

All outputs are figures and printed tables displayed inline. No files are written to disk.

**Distribution similarity metrics (Step 6 & 8.6):**

| Metric | Interpretation |
|---|---|
| KS statistic | Max distance between empirical CDFs; 0 = identical |
| Wasserstein distance (mm) | Mean "earth mover's" distance between distributions |
| JS divergence | Symmetric KL-based divergence; 0 = identical, ≤ 0.693 = maximally different |
| Overlap coefficient | Fraction of histogram area shared between the two distributions |
